# Smart Closet MVP

## Required features

- Upload a clothing image
- Save clothing information
- Display the wardrobe
- Predict the clothing category using a pretrained model
- Allow the user to correct the prediction
- Save both the prediction and corrected label
- Recommend a simple outfit
- Evaluate the model on my wardrobe images

## Clothing categories

- Top
- Pants
- Shorts
- Dress
- Jacket
- Shoes
- Other

## Optional features

- Better UI
- Weather integration
- Bulk upload
- Automatic color detection
- Background removal
- User accounts

## Deadline

Complete the MVP before August 1, 2026.
